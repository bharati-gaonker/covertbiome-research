# Data and Safety

## Allowed in this public repository

- Code operating on synthetic or properly authorized public research data.
- Dataset schemas, metadata contracts, and retrieval instructions.
- Aggregate, non-identifying research results suitable for public release.

## Do not commit

- PHI or directly identifying patient information.
- Controlled-access files unless redistribution is explicitly permitted.
- Cloud credentials, API tokens, private keys, or `.env` files.
- Private model checkpoints or unpublished partner datasets.
- Proprietary CovertBiome causal/mechanistic implementations.

Raw datasets should remain outside Git and be obtained directly from their authoritative sources under applicable terms.
